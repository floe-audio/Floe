### Can I add my own samples?

Not at the moment. Floe isn't a sampler you drop your own recordings into: it's a platform for complete, polished sample libraries, a bit like an open ROMpler. Each library comes ready to play, with its Instruments set up and presets designed around them.

We're looking into ways to expand this in the future.

If you have some programming experience, you can make your own sample libraries for Floe with its open tools: see [Library Development](../develop/develop-libraries).

### Does Floe load SFZ, SoundFont or other formats?

No. Floe loads sample libraries in its own format, an open format with similar ideas to SFZ that uses the Lua programming language.<ManualExclude types={['library']}> It also loads the older Mirage format used by some FrozenPlain libraries.</ManualExclude>
