Installing Floe is quick: [download](https://floe.audio/download) the installer for your computer, run it, and open Floe in your DAW. This page has the details for each operating system, in case you need them.

Before you start, check that your computer meets Floe's [System Requirements](../getting-started/system-requirements).

## Installing

<OSTabs>
  <OSPanel os="windows">
    1. Download the installer from the [download page](https://floe.audio/download).
    1. Extract the downloaded zip file, usually by double-clicking it.
    1. Run the installer and follow its steps. It installs both the CLAP and VST3 versions.
    1. Open your DAW and add Floe to an instrument track. If it doesn't appear, ask your DAW to rescan its plugins.

    To install by hand instead, download the manual-install zip from the same page, extract it, and move the files into your plugin folders:
    - `Floe.clap` into `C:\Program Files\Common Files\CLAP`
    - `Floe.vst3` into `C:\Program Files\Common Files\VST3`
  </OSPanel>

  <OSPanel os="macos">
    1. Download the installer for your Mac from the [download page](https://floe.audio/download). There are two versions: _Apple Silicon_ for M1, M2 and later Macs (most Macs since late 2020), and _Intel_ for older Macs. [Apple's guide](https://support.apple.com/en-us/116943) shows how to check which one you have.
    1. Double-click the download to extract it.
    1. Run the PKG installer and follow its steps. Install it to your main drive (usually _Macintosh HD_). Your libraries and presets can live on any drive.
    1. Open your DAW and add Floe to an instrument track. If it doesn't appear, ask your DAW to rescan its plugins.

    To install by hand instead, download the manual-install zip files from the same page, extract them, and move the files into your plugin folders:
    - `Floe.clap` into `/Library/Audio/Plug-Ins/CLAP`
    - `Floe.vst3` into `/Library/Audio/Plug-Ins/VST3`
    - `Floe.component` into `/Library/Audio/Plug-Ins/Components`
  </OSPanel>

  <OSPanel os="linux">
    1. Copy the installation command from the [download page](https://floe.audio/download). There's one for CLAP and one for VST3.
    1. Paste it into a terminal and run it. It creates your plugin folder if needed, downloads Floe and extracts it there.
    1. Open your DAW and add Floe to an instrument track. If it doesn't appear, ask your DAW to rescan its plugins.

    To install by hand instead, download the manual-install file from the same page and extract it into your plugin folders:
    - `Floe.clap` into `~/.clap` or `/usr/lib/clap`
    - `Floe.vst3` into `~/.vst3`, `/usr/lib/vst3` or `/usr/local/lib/vst3`
  </OSPanel>
</OSTabs>

## Updating

To update Floe, download and run the latest installer, or run the Linux command again. The new version replaces the old one and is fully backwards-compatible. If you installed by hand, replace the old files with the new ones.

Floe checks for new versions for you. When one is available, a red dot appears on the <FAIcon icon="fa-solid fa-ellipsis-v" /> menu in the top panel.

<GeneratedScreenshot name="update-indicator" alt="The red update dot on Floe's menu button" />

Open the menu and choose _Info_. The _About_ tab names the new version and gives you three options: _Download page_, _Changelog_ to see what's new, and _Ignore_, which hides the dot until an even newer version comes out.

<GeneratedScreenshot name="check-for-updates" alt="The About tab of Floe's Info panel, showing a new version" />

To stop Floe checking, untick _Check for updates_ in <FAIcon icon="fa-solid fa-cog" /> Preferences.
