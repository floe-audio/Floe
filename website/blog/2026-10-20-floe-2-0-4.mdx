Floe 2.0.4 is out now - a big update with redesigned browsers, a reworked Distortion effect, a new Limiter and lots of improvements throughout.

## Browsers

The preset, Instrument and IR browsers have been redesigned. The new Browse mode gets you to a library, preset bank, folder or tag in a few clicks, rather than scanning a long tree of filters. The browsers now feel more like a menu, open right beneath the selector you clicked, and can be resized. Filter mode is still there if you prefer the previous way of working. See the [browsers docs](/docs/usage/browsers) for a full walkthrough.

## Distortion and Limiter

The [Distortion](/docs/usage/effects#distortion) effect has been overhauled: 10 new or upgraded types, a cleaner sound with 4x oversampling, new Punish and Tilt controls, and Auto Gain to keep the volume steady as you turn up the drive. A new display previews the current shape. Existing presets and DAW projects load with the older types, kept as Legacy types.

:::danger[Screenshot needed]
The Distortion effect in the FX rack using one of the new types (e.g. Tape or Wavefolder), with the shape preview display visible and Punish/Tilt turned up enough to make the curve interesting.
:::

There's also a new [Limiter](/docs/usage/effects#limiter) effect, mainly for the end of the effects chain, with input, gain-reduction and output meters.

:::danger[Screenshot needed]
The Limiter effect in the FX rack while audio plays, with all three meters showing activity and some visible gain reduction.

## Clearer macros

You can now see macros move things: the filters, EQ, LFO, envelopes and waveform show macro modulation directly. A parameter's value popup shows its macro-adjusted value and which macros are changing it, and [Edit Range](/docs/usage/macros#editing-the-range) lets you set a destination's 0% and 100% values directly while hearing each end.

:::danger[Screenshot needed]
A layer's filter or EQ display with a macro assigned to the cutoff, showing the faint 'ghost line' of the macro-modulated response alongside the normal response.
:::

## Other highlights

- **Faster audio engine**: up to 2.5x faster in heavy granular use
- **[Share Grains](/docs/usage/playback-tab#share-grains)**: shared grains keep the same density however many notes you play, per-voice grains build chords into a dense wash
- **[Variation](/docs/usage/playback-tab#variation)** for granular layers and random LFO shapes, so a preset can repeat the exact same grain scatter or LFO movement on every note or on each key
- **[Default preset](/docs/presets/loading-presets#default-preset)**: choose what new instances of Floe open with
- More descriptive tooltips, with values shown straight away on hover
- New displays and meters: a LUFS meter, peak-hold lines, Compressor meters, a High-pass filter graph and a Bitcrush shape preview
- Redesigned effects switches: bypass, add/remove and jump to an effect in the rack from one place
- Smoother, more useful Bit Crush controls
- Swap layers and macros from their right-click menus
- LFO Amount as an MPE press and slide target
- Wider layer Pitch range of ±88 semitones
- Respond to MIDI panic messages (All Notes Off and All Sound Off)
