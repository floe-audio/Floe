Floe v2.0.0 is out now - by far the biggest release in Floe's history (and even from the Mirage days), packed with new sound-shaping tools and a redesigned UI.

{/* truncate */}

![Floe v2.0.0](/images/screenshots/overview.png)

Highlights:

- Redesigned 2-page UI, plus a distraction-free PERFORM page
- Granular synthesis
- Per-layer arpeggiator
- Creative randomisation strip for exploring preset variations
- Visual filters, EQ and LFO with draggable nodes
- New stereo width controls, LFO shapes, and a Modern compressor algorithm
- Undo/redo, right-click menus, and streamlined browsers throughout
- New `.floe-pkg` package format, plus encrypted packages for developers

And loads more besides - see the full [changelog](/docs/changelog) for everything.

As always, Floe is free and open source. Grab v2.0.0 from the [download page](/download).

### What's next
We're working on:
- New video walkthrough for Floe
- An update all free community packages including new presets
- New FrozenPlain product
