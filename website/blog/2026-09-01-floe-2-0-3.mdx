Floe 2.0.3 is out now with MPE support and a new Performance Controls panel.

{/* truncate */}

- **[MPE support](/docs/usage/midi#mpe)**: enable it in the new Performance Controls panel for per-note pitch bend, press and slide, with per-layer control over what press and slide do. CLAP per-note expressions are supported too
- **[Performance Controls panel](/docs/usage/performance-controls)**: replaces the old Instance Config and MIDI CC Assignments panels - set what new instances start with, and save named profiles to switch between setups
- Copy and paste effects, including the whole FX rack, between presets
- Right-click and double-click entry for macro destination knobs
- Activate multiple encrypted packages at once from a single license file
- A bunch of crash fixes and stuck-note fixes
