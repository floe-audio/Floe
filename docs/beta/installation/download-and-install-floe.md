# Install Floe

> Instructions for downloading and installing Floe on Windows, macOS, and Linux

Installing Floe is quick: [download](https://floe.audio/download) the installer for your computer, run it, and open Floe in your DAW. This page has the details for each operating system, in case you need them.

Before you start, check that your computer meets Floe's [System Requirements](/docs/beta/getting-started/system-requirements).

## Installing

Windows

macOS

Linux

1.  Download the installer from the [download page](https://floe.audio/download).
2.  Extract the downloaded zip file, usually by double-clicking it.
3.  Run the installer and follow its steps. It installs both the CLAP and VST3 versions.
4.  Open your DAW and add Floe to an instrument track. If it doesn't appear, ask your DAW to rescan its plugins.

To install by hand instead, download the manual-install zip from the same page, extract it, and move the files into your plugin folders:

-   `Floe.clap` into `C:\Program Files\Common Files\CLAP`
-   `Floe.vst3` into `C:\Program Files\Common Files\VST3`

Once Floe is installed, it needs some sounds. See [Install Packages](/docs/beta/installation/install-packages) to add your sample libraries and presets.

## Updating

To update Floe, download and run the latest installer, or run the Linux command again. The new version replaces the old one and is fully backwards-compatible. If you installed by hand, replace the old files with the new ones.

Floe checks for new versions for you. When one is available, a red dot appears on the menu in the top panel.

![The red update dot on Floe's menu button](https://assets.floe.audio/website/screenshots/update-indicator.ca15b747cc83e19c.png)

Open the menu and choose _Info_. The _About_ tab names the new version and gives you three options: _Download page_, _Changelog_ to see what's new, and _Ignore_, which hides the dot until an even newer version comes out.

![The About tab of Floe's Info panel, showing a new version](https://assets.floe.audio/website/screenshots/check-for-updates.298412ee4fa33aaf.png)

To stop Floe checking, untick _Check for updates_ in Preferences.

The same place has an option to be told about beta versions too if you want to try new features early: see [Beta Testing](/docs/beta/about-the-project/beta-testing).
