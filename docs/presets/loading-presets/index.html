Loading Presets

Presets are the quickest way into Floe's sounds. Each one is a complete, production-ready setup. Load one and it's ready to play in your track straight away.

The factory presets give you a whole palette of sounds to start from. Their names hint at the sound or how you might use it, and they're sorted into folders so you can narrow down to the kind of sound you need.

Presets are also how you keep sounds of your own. Save it as a preset and you can load it into any instance of Floe in the future. See Saving Presets.

Loading a preset replaces all your settings, except for your Performance Controls. You can always use the Undo button in the top panel to undo a preset load.

The preset box​

The preset box in the top panel shows what's loaded and gives you quick ways to move between presets.

On the left is the name of the current preset, with a short description underneath. If the preset has changed since it was loaded, Floe shows (modified) after the name. Click the name to open the preset browser.

The buttons on the right are:

  • Previous/Next — step to the previous or next preset.
  • Random — jump to a random preset.
  • Save — open the Save Preset panel. See Saving Presets.
  • Load from file — load a preset file from anywhere on your computer, such as one someone has sent you. It doesn't need to be in one of Floe's preset folders.

Right-click the name for two more options. Load Blank Preset resets every setting to its default and clears all the Instruments and IRs, ready to build a sound from scratch. Open Containing Folder shows the current preset's file in your file manager.

Finding presets​

The preset browser is the place for browsing deliberately. Choose a folder or some tags in the dark panel on the right, then click presets on the left to hear them. The browser stays open, so you can play a few notes, click the next preset, and play again. Once you've loaded a preset, if you move your cursor outside of the browser it will close.

See Browsers for everything it can do: filtering, search, keyboard navigation and more.

For a quick audition without the browser, use the previous and next arrows, and . The large arrows on the Perform page do the same. Both follow the filters you've set in the preset browser, so if you've chosen a particular folder or tag there, the arrows only step between presets that match. When you reach the end of the list, they wrap round to the start. Random follows the same filters, which makes it a handy way to dip into a chosen corner of your presets. For Floe's other ways to bring in an element of chance, see Randomisation.

Default preset​

The default preset is the one a new instance of Floe opens with, instead of a blank state.

There are two ways to set the default preset:

  • Right-click any preset in the browser and choose Set as Default Preset. The preset is then marked with a icon in the browser.
  • Or alternatively, load the preset, then open Preferences and, in the Default Preset row on the General tab, click Use Current Preset. Click the button to remove the default, so Floe opens blank again.

The default preset doesn't apply if you open a saved DAW project — Floe uses the sound saved in the project as usual.

After installing a preset bank a default preset will be set for you. You can always overwrite this using the options above. Once you set a custom default, installing further packages will not interfere with your choice.
