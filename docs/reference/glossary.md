# Glossary

> {/*

A few words have a specific meaning throughout this manual:

-   **[Package](/docs/installation/install-packages#what-is-a-package)** — the file you download to install Floe content (`.floe-pkg` or `.floe-pkg-enc`). Packages may contain sample libraries, presets, or both.
-   **[Sample Library](/docs/reference/sample-libraries)** — a collection of mapped, playable sounds along with images, tags, and other metadata. Sample libraries provide the Instruments and impulse responses that Floe loads.
-   **[Layer](/docs/usage/layers)** — one of the three identical channels, which all play together. Each layer holds an Instrument and has its own playback, envelope, LFO and EQ controls.
-   **[Instrument](/docs/reference/instruments)** — a playable sound source from a sample library, loaded into one of the layers. It might be a single recording or many samples mapped across the keyboard.
-   **[Impulse Response](/docs/usage/effects#convolution-reverb)** — a recording from a sample library that gives the Convolution Reverb effect its character.
-   **[Preset](/docs/presets/loading-presets)** — a saved sound: a snapshot of every parameter and option, along with a name, description and tags.
